# Weekend Trip Planner

## Overview

A small web app that plans a cheap trip around Scotland, starting from Aberdeen. You tell it how much you've got to spend, how long you've got and what you're into, and it puts together a plan you could actually go and do.

## Target user

Students at the University of Aberdeen who want to get out of the city for a day or a weekend but don't have a car or much money, and don't want to spend an evening piecing together bus routes and things to do.

## Functionality

- Take a few simple inputs from the user, including their budget
- Plan a trip that starts and ends in Aberdeen and gets around by public transport
- Give a rough cost for the trip so the user can see whether it fits their budget
- Show the plan in a way that's easy to read on a phone

## Specifications

- It's a small web app that runs on the user's own machine.
- No accounts, no external APIs and no API keys.
- Prices are in pounds (£).
- Keep it small. It needs to be built in an afternoon.

## Tech stack

- Plain HTML, CSS and JavaScript as a single-page app
- No frameworks and no build step
- It should run with any simple static server, or by opening it in a browser

## Example uses

These are the kind of things we expect people to ask for:

- "I've got £40 and a free Saturday. I like being outdoors."
- "Two days, about £120, somewhere with good food and a bit of history."
- "Cheapest possible day out from Aberdeen this weekend."
